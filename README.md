# SRT to MD & Anki (Finetuned Llama-3-8B)

Здесь находятся файлы обученной модели, которая автоматически превращает SRT-субтитры в подробные Markdown-конспекты и карточки для Anki (в формате TSV).

## Состав папки:
- `lora_model/` — обученные веса (LoRA адаптеры) для модели Llama-3-8B-Instruct.
- `inference.py` — готовый скрипт для использования обученной модели.
- `finetune.py` — исходный скрипт, которым эта модель обучалась (оставлен на память).
- `train_dataset.jsonl` — датасет, на котором происходило обучение.

## Как использовать модель?

Благодаря автоматизации, запуск модели стал невероятно простым. Вы можете генерировать конспекты, TSV таблицы и готовые `.apkg` архивы для Anki всего одной командой.

### 1. Подготовка окружения (установка зависимостей)
Откройте терминал в этой папке (`~/Downloads/trained_models/srt-md-apkg`) и выполните эти команды один раз:

```bash
# Создаем виртуальное окружение
python3 -m venv .venv
source .venv/bin/activate

# Устанавливаем все зависимости разом
pip install -r requirements.txt
```

### 2. Запуск генерации
Для запуска мы подготовили скрипт-обертку `srt2anki`, который можно вызывать из любой папки:

```bash
./srt2anki /путь/к/вашему/файлу.srt
```

**Что произойдет:**
1. Скрипт сам активирует нужное окружение и загрузит модель.
2. Модель сгенерирует подробный Markdown-конспект и сохранит его в файл `_notes.md`.
3. Автоматически извлечет карточки и сохранит их в `.tsv` файл.
4. **Сгенерирует готовую колоду `.apkg`**, которую можно импортировать в Anki двойным кликом!

### 💡 Лайфхак: Доступ из любой точки системы
Чтобы не писать полный путь к скрипту каждый раз, вы можете создать глобальный `alias` (псевдоним). Добавьте эту строку в конец вашего файла `~/.bashrc` (или `~/.zshrc`):

```bash
alias srt2anki="/home/htp/Downloads/trained_models/srt-md-apkg/srt2anki"
```

После этого перезапустите терминал (или выполните `source ~/.bashrc`). Теперь вы сможете обрабатывать субтитры из любой папки компьютера простой командой:

```bash
srt2anki video.srt
```

### Альтернативные способы запуска
Папка `lora_model` содержит стандартные веса HuggingFace PEFT. Вы можете объединить их с базовой моделью и перевести в формат GGUF (для запуска через Ollama / LM Studio) с помощью встроенных утилит Unsloth, если в будущем вам потребуется полностью автономный файл модели.
